2. Ranking-policy identity and canonicalization

Verify that ranking behavior affecting identity is represented completely and deterministically.

This includes, as applicable:

* ranking policy version
* scope behavior
* bucket definitions
* bucket order
* score direction
* tie-breaking rules
* limit application
* component ordering
* component-summary ordering
* missing-value behavior
* actionable/non-actionable behavior
* validation rules

Verify:

* string framing handles embedded delimiters
* UTF-8 values are deterministic
* integer and boolean encoding is stable
* floating-point encoding is locale-independent
* `+0.0` and `-0.0` canonicalize consistently where semantically equivalent
* NaN and infinity are rejected where unsupported
* hashes are derived from canonical text
* canonical text remains the authority when hash equality alone is insufficient
* identity changes whenever ranking behavior changes
* identity remains stable when behavior and inputs are unchanged

3. Scope canonicalization

Verify all supported ranking scopes.

Confirm:

* every defined scope has a stable canonical representation
* no two scopes canonicalize identically
* scope-specific fields are included exactly when applicable
* invalid or incomplete scope definitions are rejected

4. Membership and snapshot identity

Verify deterministic recommendation membership identity.

Confirm:

* source recommendation identity is complete
* ordering is canonical

* maximum input count is enforced at all relevant public boundaries

5. Ranking validation and bucket behavior

* bucket ordering is deterministic
* tie-breaking is complete and stable
* limit application occurs at the documented stage
* repeated ranking of identical inputs produces byte-for-byte equivalent canonical output where intended

6. Comparison semantics

Confirm:

* incompatible identities are not silently compared
* ranks must be valid
* added, removed, moved, unchanged, and otherwise supported classifications are correct
