GOAL

Implement Phase 4C Step 1 as a pure, deterministic domain layer for
manually converting an already-reviewed recommendation into a proposed
experiment specification.

This step defines and tests the conversion contract only.

It must not persist a conversion, create an experiment, queue an
experiment, modify scheduler state, or execute any recommendation.

CORE REQUIREMENTS

-   Manual authorization is mandatory.
-   Ranking remains advisory and never authorizes conversion.
-   Support only mutation families already represented by the
    recommendation subsystem.
-   Preserve every non-mutated source experiment parameter.
-   Reject stale, inconsistent, blocked, unsupported, or ambiguous
    recommendations.
-   Produce deterministic canonical representations and identity hashes.
-   No PostgreSQL access.
-   No scheduler interaction.
-   No CLI commands.
-   No experiment creation.
-   No persistence.
-   Pure domain implementation with comprehensive deterministic unit
    tests.
