FEATURE INTENT
Measure how much the completed 8-close path moved against its eventual net
direction before reaching the final completed close.

This complements:
- directional efficiency: net displacement / total path length
- sign persistence: continuation versus alternation of adjacent move signs
- direction imbalance: count balance of positive versus negative moves

The new feature asks a different question:

    "Relative to the total path traveled, how deep was the worst counter-
     directional excursion from the starting close?"

A clean monotonic move has value 0.
A path that first moves substantially against its eventual direction and then
reverses to finish in the net direction has a larger positive value.

FEATURE DEFINITION
Use only the eight COMPLETED closes strictly prior to current Tensor row t:

    C0 = C_{t-8}
    C1 = C_{t-7}
    ...
    C7 = C_{t-1}

Define:

    net = C7 - C0

    path =
        sum_{i=1..7} abs(Ci - C{i-1})

If all eight closes are finite, path is finite and > 0, and net != 0:

For net > 0:
    adverse =
        max(0, C0 - min(C0,C1,...,C7))

For net < 0:
    adverse =
        max(0, max(C0,C1,...,C7) - C0)

Then:

    directional_adverse_excursion =
        adverse / path

If:
- fewer than eight completed closes are retained, or
- any required close is non-finite, or
- any required increment is non-finite, or
- path <= 0 or non-finite, or
- net == 0 or non-finite, or
- adverse/result is non-finite,

emit 0.

INTERPRETATION
- 0 means no excursion against the eventual net direction from the starting
  close, or a degenerate/net-zero window.
- Positive values indicate a counter-directional excursion before the final
  completed close established the net direction.
- Larger values mean more of the completed path was spent reaching a worse
  level opposite the eventual direction.

For valid finite data, adverse <= path, so the natural output range is [0,1].

Do not clip.
Do not add an epsilon denominator.
Do not magnitude-scale beyond dividing adverse by total path.

IMPORTANT DIRECTION SEMANTICS
The direction is determined ONLY by:

    sign(C7 - C0)

Do not infer direction from:
- majority up/down moves,
- sign-persistence,
- regression slope,
- candle bodies,
- current row t.

For net == 0, emit exactly 0 because there is no eventual net direction against
which "adverse" can be defined.
