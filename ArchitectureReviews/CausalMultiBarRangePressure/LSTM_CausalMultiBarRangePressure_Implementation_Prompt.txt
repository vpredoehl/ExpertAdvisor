# LSTM Causal Multi-Bar Range Pressure Feature — Implementation

## Objective

Implement one small, production-quality causal LSTM input feature:

**causal multi-bar range pressure / rolling close position**

The feature should measure where the current bar's close lies within the high/low range formed by a fixed trailing window of bars.

This is intended to complement—not duplicate—the existing single-bar causal close-location/range-position feature.

Work directly in the current repository. Inspect the existing feature pipeline and follow its established conventions rather than inventing a parallel mechanism.

## Required semantic definition

Use a fixed causal lookback of **16 bars**, unless repository conventions provide a compelling reason that this exact constant would violate an existing feature contract.

For bar `t`:

    rolling_high_t = max(high[t-i]) for i = 0..15
    rolling_low_t  = min(low[t-i])  for i = 0..15

Define:

    range_pressure_t =
        2 * (close[t] - rolling_low_t)
          / (rolling_high_t - rolling_low_t)
        - 1

Thus the ordinary range is approximately:

    -1 = close at trailing-window low
     0 = close at trailing-window midpoint
    +1 = close at trailing-window high

The implementation must have explicit deterministic behavior for a zero or effectively-zero rolling range. Prefer `0.0` unless an existing repository convention establishes another neutral value.

Do not use future bars.

Do not center the window.

Do not derive the trailing high/low using data after bar `t`.

The current bar MAY be included and SHOULD be included according to the definition above.

## Causality requirements

This is a strict causal feature.

For feature value at time `t`, only observations with index `<= t` may affect the result.

Add a causality regression test demonstrating that modifying bars after `t` cannot change the feature value at `t`.

Also verify boundary/warmup behavior explicitly.

Follow the repository's existing feature warmup policy and tensor construction conventions. Do not silently introduce a new warmup policy.
