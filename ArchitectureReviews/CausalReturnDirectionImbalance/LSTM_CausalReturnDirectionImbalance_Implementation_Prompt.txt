FEATURE INTENT
This feature measures the directional breadth of the seven completed
close-to-close moves inside the retained 8-close window.

It should distinguish:
- mostly positive completed moves -> positive value
- mostly negative completed moves -> negative value
- balanced up/down moves -> near zero

This is intentionally different from:
- directional efficiency: net displacement / total path magnitude
- sign persistence: continuation vs alternation between adjacent move signs

Return-direction imbalance ignores adjacency and ignores move magnitude. It
measures only the balance of positive versus negative completed moves.

FEATURE DEFINITION
Use only the eight COMPLETED closes strictly prior to current Tensor row t:

    C_{t-8}, C_{t-7}, ..., C_{t-1}

Define seven completed close increments:

    d_i = C_i - C_{i-1}

for the seven consecutive pairs inside the retained 8-close window.

Define:

    direction_score(d) =
        +1 if d > 0
        -1 if d < 0
         0 if d == 0

Then:

    return_direction_imbalance =
        (1/7) * sum(direction_score(d_i), i=1..7)

when all eight retained closes and all seven increments are finite.

Otherwise emit 0.

Interpretation:
- +1 = all seven completed moves positive
- -1 = all seven completed moves negative
-  0 = exact directional balance only when the seven scores sum to zero;
       because there are seven increments, exact zero requires at least one
       zero move unless positive/negative counts plus zeros balance
- intermediate values occur in increments of 1/7 for finite valid data

Do not magnitude-weight.
Do not use return sizes.
Do not use adjacent-pair persistence.
Do not normalize by volatility.
Do not add a second feature.
