Inference Profitability Persistence
===================================

Profitability Phase 1 records immutable observations generated by completed
inference.  It does not alter recommendation, campaign, scheduler
continuation, checkpoint-policy, or training decisions.

Metric semantics
----------------

The version-1 metric applies only to three-class Up/Neutral/Down inference.
Every evaluable inference window is a prediction.  A prediction is actionable
when the predicted class is Up or Down and both the decision close and the
terminal-horizon close are finite and positive.  Up contributes
``ln(terminal_close / decision_close)``; Down contributes its negative.
Neutral is not actionable.  Positive directional returns are wins, negative
directional returns are losses, and an exactly zero directional return is
actionable but is neither a win nor a loss.

The aggregate is a sum of terminal-horizon directional log returns over
actionable predictions.  It has no spread, commission, slippage, capital
allocation, position sizing, leverage, or overlapping-trade capital model and
must not be interpreted as portfolio P&L.  No return clipping is applied.
When actionable count is zero, aggregate and gross sums are valid zero values
and the per-actionable average is ``NULL``.

Scope and provenance
--------------------

``inference_scope='final'`` requires a null checkpoint identity.
``inference_scope='checkpoint'`` requires a checkpoint evaluation identity.
Migration ``073_inference_profitability_observation.sql`` enforces this shape
and validates every insert against a completed ``inference_eval_result``, its
model, experiment, range, and checkpoint provenance.

Checkpoint observations require an experiment.  A final observation for a
legacy model may retain a null ``experiment_id`` only when the authoritative
model row also has no experiment linkage; this preserves legacy infer-all
compatibility without inventing provenance.  Modern scheduler final evidence
has an experiment linkage.

The metric definition is stored as canonical versioned text plus an FNV-1a
identity.  Source content is identified by an ordered FNV-1a stream over each
profitability input: ordinal, predicted class, decision-close float bits, and
terminal-close float bits.  The observation identity includes full
provenance, metric identity, source identity, and canonical primitive
statistics.  Canonical text is the authoritative unique identity; the compact
hash is an indexed diagnostic accelerator.

Identical evidence and definition reuse the same observation row.  Changed
source content or definition creates another immutable observation and never
updates the prior row.  Historical inference rows are not backfilled because
their exact ordered per-window inputs are not retained.

Operational boundary
--------------------

The common final/checkpoint inference evaluator owns the only calculation.
Persistence occurs in the same database transaction as successful inference
evaluation persistence.  The diagnostic
``INFERENCE_PROFITABILITY_OBSERVATION_PERSISTED`` reports observation,
scope, experiment, model, inference-result and checkpoint identities,
actionable count, aggregate statistic, and metric-definition identity.

Consumers remain future work.  In particular, this observation is not read by
Campaign Manager, recommendation scoring, scheduler continuation, or
checkpoint stop/continue policy in Phase 1.
